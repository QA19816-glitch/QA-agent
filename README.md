# QA-agent 技能仓库

一个以测试与 QA 技能为核心、同时提供通用工程能力的技能仓库。

## 目录

| 目录 | 用途 |
| --- | --- |
| [`claude-skills/`](./claude-skills) | Claude Code 技能包 |
| [`codex-skills/`](./codex-skills) | Codex 技能包 |
| [`tools/`](./tools) | 仓库维护与 QA 自动化脚本 |

## 使用

Claude Code：

```bash
bash claude-skills/scripts/install.sh all
```

Codex：

```bash
bash codex-skills/scripts/install.sh
```
