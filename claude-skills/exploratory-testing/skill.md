# Exploratory Testing

通过目标引导的自由探索发现用例之外的缺陷，输出结构化发现报告。

## 核心理念

- **有目的地探索**，不是随机点击——每次探索有明确的「测试章程（Charter）」
- 记录「发现 + 路径 + 证据」，确保可复现
- 区分「缺陷」「疑问」「观察」三类记录
- 时间盒制：每个 Charter 30-60 分钟，超时收尾

---

## Phase 0 — 制定探索章程（Charter）

每次探索前确定：
```
Charter 模板：
探索 [功能/区域]
使用 [技术/手段/数据]
发现 [目标：崩溃/数据问题/权限漏洞/体验缺陷/...]
时间限制：[30/60] 分钟
```

**常用 Charter 方向：**
- 探索「边界值」：最大/最小/空/特殊字符/超长文本
- 探索「权限边界」：未登录/过期Token/越权访问
- 探索「状态转换」：快速切换/中断操作/网络断开再恢复
- 探索「异常输入」：SQL注入字符/emoji/特殊符号/超大文件
- 探索「并发操作」：快速双击/多窗口同时操作
- 探索「历史数据」：空数据/大量数据/脏数据
- 探索「错误恢复」：强制中断后再操作/清除缓存后状态

## Phase 1 — 执行探索

### 记录模板（每发现一条填写）

```markdown
### 发现 #N
- **类型**：❌ 缺陷 / ⚠️ 疑问 / 📝 观察
- **区域**：[功能模块]
- **路径**：
  1. [操作步骤1]
  2. [操作步骤2]
  3. [触发条件]
- **实际结果**：[描述]
- **预期结果**：[描述]
- **证据**：[截图路径 / 日志]
- **严重度估计**：P1/P2/P3
```

### 探索技巧清单

**输入变异：**
- [ ] 空值/null/undefined
- [ ] 超长字符串（1000字符以上）
- [ ] 特殊字符：`<>"';\`&%$#@!`
- [ ] emoji：😀💯🔥
- [ ] 纯空格 / 首尾空格
- [ ] 负数 / 0 / 极大值
- [ ] 非预期类型（数字字段填字母）

**状态破坏：**
- [ ] 登录中途刷新
- [ ] 表单填写一半后退
- [ ] 同一账号两个窗口操作
- [ ] 快速连续点击按钮（3-5次）
- [ ] 网络节流（弱网/断网）中操作
- [ ] 浏览器前进/后退
- [ ] 深链接直接跳转到需要前置状态的页面

**权限越界：**
- [ ] 未登录访问需权限页面
- [ ] 普通用户访问管理员接口
- [ ] 修改URL参数中的ID（IDOR检测）
- [ ] 修改请求体中的user_id/product_id

**数据边界：**
- [ ] 空列表页的交互
- [ ] 单条数据时的交互
- [ ] 大量数据（分页边界、滚动加载末端）
- [ ] 数据已删除后再访问

## Phase 2 — 时间盒管理

```
[00:00-10:00] 快速熟悉目标区域，记录结构和入口
[10:00-40:00] 按 Charter 深入探索，每发现一条立即记录
[40:00-50:00] 扩大范围：关联功能/上下游
[50:00-60:00] 整理发现，补充截图，评估严重度
```

---

## Phase 3 — 输出探索报告

```markdown
## 探索性测试报告
- Charter：探索 [XX功能] / 时间：60分钟
- 测试人：XX / 日期：YYYY-MM-DD
- 环境：[URL]

### 发现汇总
| # | 类型 | 严重度 | 区域 | 简述 |
|---|------|--------|------|------|
| 1 | ❌ 缺陷 | P2 | 会员购买 | 空订单列表点击"查看"崩溃 |
| 2 | ⚠️ 疑问 | P3 | 个人中心 | 头像上传超5MB无提示 |
| 3 | 📝 观察 | - | 搜索 | 搜索结果排序逻辑不一致 |

### 覆盖区域
- ✅ 会员购买流程
- ✅ 个人中心编辑
- ⬜ 视频播放（未探索）

### 建议下一步
- 缺陷 #1 建议立即提 BUG（P2）
- 疑问 #2 需确认产品需求文档
```
